# Public news feed

PR #12 populated `intelligence_*` event tables, but the public site still called only `listNews`, which reads official-news editions. This change connects existing open-web events to `/` and `/haberler` and adds `/olay/{eventId}` source-backed detail pages.

Both feeds share one server-rendered card component and the same merge/sort function. The visible date is the selected source report's actual publication timestamp, using Turkish date formatting. Crawl/check/update timestamps stay separately labeled. Sources without a known publication date sort after dated reports. TRT and AA filters are available alongside the existing official-institution filters.

Cards are deterministically labeled as Gündem, Spor, Yaşam, Eğitim, Ekonomi or Dünya from the structured event kind and grounded headline/excerpt. Son Dakika is a separate rolling filter for reports whose source publication time is within the latest 24 hours; an unknown crawl time never makes a report breaking news. Category and source filters can be combined, and newly collected reports need no manual classification or database rewrite.

The public database projection reads only the `live` namespace, active source configurations, non-fixture open-web reports, and the latest immutable revision of each canonical report. Official bridge-only events do not duplicate the existing official feed. Future-dated reports and URLs outside the current source host policy are excluded. Claim corroboration is recomputed from eligible current reports, and evidence quotes are checked against those stored reports. A disabled source stops contributing to the next dynamic request. Detail pages show source headlines/short excerpts, direct links, attributed structured values, explicit conflicts, evidence sentences and update history. Event pages currently use `noindex` and are not added to the sitemap; the existing official sitemap remains intact.

A stopped or failing local crawler does not hide already collected news: source-check delays are visible on the detail page, and timestamps are not fabricated to look fresh. Crawling remains in Docker; public web requests only read PostgreSQL. Home retains its existing 60-second revalidation, while the feed and detail routes are dynamic. Official and event reads fail independently, preserving the available half of the feed if one pipeline is unavailable. The official admin list continues using the official feed.

No migration, new secret, new worker schedule or continuous-server requirement is introduced. When the Mac and Docker are running, the existing worker collects news and the public feed picks up the persisted events. Tests cover shared publication dates, public filtering, current revisions, source removal, conflicts, stale checks, direct links and browser source navigation.
